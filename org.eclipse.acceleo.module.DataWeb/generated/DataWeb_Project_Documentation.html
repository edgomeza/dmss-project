📋 ¿Qué es DataWeb DSL?

DataWeb es un lenguaje específico de dominio (DSL) diseñado para automatizar la generación de aplicaciones web y de escritorio basadas en datos. El sistema permite a los desarrolladores crear aplicaciones completas simplemente modelando la estructura de datos y las operaciones deseadas.

🚀 Características Principales

  • Generación automática de aplicaciones web (HTML/CSS/JavaScript)
  • Generación de aplicaciones de escritorio (Java)
  • Sistema completo de operaciones CRUD (Crear, Leer, Actualizar, Borrar)
  • Gestión de roles y permisos de usuario
  • Sistema de encuestas y cuestionarios con evaluación
  • Integración con redes sociales (Twitter, Facebook, Instagram, LinkedIn)
  • Soporte para fuentes RSS
  • Editor gráfico intuitivo con validación en tiempo real
  • Validación mediante restricciones OCL
